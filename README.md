# Parampreet Singh Portfolio

A polished, responsive portfolio built with **React.js + Tailwind CSS + Vite**.

## Features
- Responsive desktop/mobile navigation
- Active section navigation
- Modern dark UI
- About, skills, projects, education and contact sections
- Accessible buttons and links
- Inline SVG icons (no `lucide-react` dependency)
- Live project links
- No external icon package required

## Run

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

## Important
Replace the placeholder GitHub and LinkedIn URLs in `src/main.jsx` with your real profiles.

Project URLs already use the links from the supplied resume.
